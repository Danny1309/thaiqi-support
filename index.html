Quick help

  • Dashboard shows “Waiting for location…” → iPhone Settings → Privacy & Security → Location Services → ThaiQI → allow While Using.
  • Map shows no values on tap → make sure you have internet and Google Air Quality API billing enabled.
  • Units look weird → ThaiQI formats concentrations as µg/m³.
  • Alerts not firing → enable Notifications for ThaiQI in iPhone Settings, then set threshold in ThaiQI Settings.

Troubleshooting

  • Restart the app after changing permissions.
  • Check your network (Wi-Fi/LTE).
  • If you’re using your own API keys, confirm they’re active and not restricted incorrectly.
